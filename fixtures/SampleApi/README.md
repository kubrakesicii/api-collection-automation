# Frozen sample API (test input)

A frozen copy of the 15-endpoint sample API (3 controllers, CRUD each). The tests analyse THIS copy, never `sample-api/`, so the real
sample API can gain, lose or change endpoints without breaking them. Do not edit these files; if a test needs a different API, add
another fixture next to it.

The committed `fixtures/postman/sample-api.*` files and `fixtures/examples/examples.sample-api.json` belong to this copy.
